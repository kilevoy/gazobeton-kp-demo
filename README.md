# Дом из газобетона: интерактивное КП за минуты

Демонстрация конвейера «проект из интернета → КП» для частного дома: расчёт газобетона, теплотехника по месту стройки, эскизные чертежи, 3D с мебелью, раскладка блоков, логистика и заявка на счёт.

Дом 10,9 × 16,0 м, 125,9 м², три спальни, вальмовая кровля, Челябинск. Исходник — план из интернета без размеров: габариты восстановлены по площадям комнат.

Сайт: https://kilevoy.github.io/gazobeton-kp-demo/
